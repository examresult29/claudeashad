Fonts used to draw the return

Carlito-Regular.ttf, Carlito-Bold.ttf
  Carlito by tyPoland Lukasz Dziedzic, metric-compatible with Calibri.
  SIL Open Font License 1.1 (see OFL-Carlito.txt). Unmodified.

FreeSerif-taka-subset.ttf
  Only the Bengali Taka sign from GNU FreeSerif (GNU FreeFont), re-mapped to the
  "$" code point so the PDF library draws it without Bengali text shaping.
  Modified from FreeSerif.ttf. License: GNU GPL version 3 or later, with the
  GNU FreeFont font exception (documents made with the font are not covered by the GPL).

Times New Roman and Arial text in the PDF uses the standard PDF fonts Times and
Helvetica, which every PDF viewer provides, as the original Excel PDF did.
